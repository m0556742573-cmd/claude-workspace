# תוכנית בנייה — גרסה 2 של הדוגמית

**מעמד: ממתינה לאישור של יצחק.** לפי [`../CLAUDE.md`](../CLAUDE.md), הבנייה מתחילה רק אחרי אישור מפורש, ואז רצה עד הסוף בלי עצירות.

**הרקע:** יצחק ניסה את גרסה 1 ואמר *"סקיצה ראשונית ונחמדה, אך ממש לא מוכנה"*, וסימן את כל ארבעת המישורים: **נראית כמו סקיצה · חסרות פונקציות · השימוש מסורבל · התוכן לא אמיתי.**

**היעד שאני ממליץ עליו: מוכנה להראות למציגים.** זה השער שחוסם את כל השאר (W-001), ומה שיחזור משם יכוון את המערכת האמיתית. **לא בונים את המערכת האמיתית בשלב הזה.**

---

## 1. נראית כמו סקיצה

**⭐ הבעיה הכי גדולה היא לא הצבעים. זה סרגל "מכונת הזמן".** חמישה שלבים ממוספרים בראש המסך גורמים לזה להיראות ככלי פנימי ולא כמוצר. **במוצר האמיתי אין "שלבים", יש מסכים.**

| מה נעשה | במקום מה |
|---|---|
| **ניווט של מוצר:** שלושה מסכים בלבד — **הדוכן · מי היה אצלי · CRM** — ברצועה תחתונה נוחה לאגודל | סרגל חמישה שלבים ממוספרים |
| **מכונת הזמן עוברת לתפריט ההדגמה** | תופסת את מרכז המסך |
| **הגדרות העסק הופכות לכפתור גלגל שיניים**, לא לשלב במסע | "שלב 1" |
| **זהות חזותית אמיתית:** טיפוגרפיה עברית גדולה יותר, היררכיה ברורה, צבע אחד דומיננטי במקום כחול גנרי, ומצבי ריק מעוצבים | מסך תכליתי |

## 2. חסרות פונקציות

| מה נוסף | למה |
|---|---|
| **חיפוש לפי טלפון** | מבקר מוסר מספר, או שהוא מופיע בשיחה |
| **חיפוש בתוך הלידים שלי** | היום אפשר לחפש רק ברשימת המבקרים |
| **סינון ומיון ב"מי היה אצלי"** | לפי חום, לפי תחום עניין, לפי שעה |
| **מחיקת ליד ואיחוד כפולים** | טעויות קורות, וכרגע אין דרך לתקן |
| **ייצוא** לאקסל ולטקסט לוואטסאפ | *"המידע שלי"* הוא חלק מהערך |
| **חיוג ישיר וכתיבה בוואטסאפ** מכרטיס הליד | ב-CRM זה הפעולה הכי נפוצה |
| **היסטוריית ליד**: מה קרה ומתי | היום רואים רק את המצב הנוכחי |
| **תזכורות שנראות בפועל** | היום הן מחושבות ולא מוצגות כהתראה |

## 3. השימוש מסורבל

**⚠️ כאן אני צריך ממך דוגמה אחת קונקרטית**, אחרת אני מנחש. בינתיים אלה שלושת החשודים שלי:
1. **מעבר בין המסכים** דורש לכוון לסרגל הקטן למעלה. הרצועה התחתונה תפתור.
2. **החזרה האוטומטית** אולי מלחיצה. אפשר להוסיף כיבוי שלה בהגדרות.
3. **"עוד" מוסתר מדי**, ובעל מוסד מצדיק פתיחה אוטומטית.

## 4. התוכן לא אמיתי

- **מסך פתיחה קצר** שמסביר בעשר שניות מה רואים ולמי זה נועד.
- **עסק לדוגמה מלא**: שם, תחום, 6 מוצרים אמיתיים, קטלוג לדוגמה.
- **שם התערוכה והתאריך האמיתיים**, ברגע שיהיו (W-007).
- **נוסחים בעברית נקייה** בכל מסך, כולל מצבי ריק ושגיאות.
