## מקרא עמודת "סוג" — ומה היא עונה עליו

**שני צירים.** הראשון: **מי כותב את השורה.** השני: **האם לטבלה יש זהות משלה, או שהיא קיימת רק כדי לשרת אחרת.**

| הציר הראשון | מי כותב | דוגמה |
|---|---|---|
| **הגדרה** | **המשרד** — מעצב בה את המערכת | `services` · `tags` |
| **חוק** | **נזרע ממקור**, ואדם רשאי לדרוס | `holidays` · `entity_type_thresholds` |
| **חי** | **בני אדם מקלידים** ביום-יום | `clients` · `deals` |
| **מיוצר** | **המערכת כותבת. איש לא מקליד** | `obligations` · `reminders` |

| הציר השני | מה זה |
|---|---|
| **מרכזית** | זהות משלה. **מסך משלה** |
| **מערכת** | lookup, קישור, או טבלת פירוט — **חלק ממסך אחר** |
| **View** | נגזר, לא מאוחסן |

### מה המיון עונה עליו

| הצירוף | מה נדרש | כמה |
|---|---|---|
| הגדרה/מרכזית + חוק/מרכזית | **מסך עיצוב מורכב** | **6** |
| הגדרה/מערכת + חוק/מערכת | **מסך רשימה פשוט** | **19** |
| חי/מרכזית | **מסך הזנה מלא** | **12** |
| חי/מערכת | **חלק ממסך אחר**, לא מסך משלה | **8** |
| מיוצר | ❌ **לא מסך — אוטומציה.** ומסך *צפייה* בלבד | **4** + 5 Views |

**זה מדייק את "~22 מסכי ניהול" מ-[`decisions/0009`](../decisions/0009-definition-versus-runtime.md): בפועל 6 מורכבים ו-19 פשוטים.**
