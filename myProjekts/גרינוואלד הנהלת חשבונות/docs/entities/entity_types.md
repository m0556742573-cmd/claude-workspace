# איפיון ישות — סוג ישות / ייחוס (ישות 4 במודל המקורי)

**סטטוס: שלד מינימלי בלבד.** נוצר כתלות-FK מ-`clients.entity_type_id` — עדיין לא עבר איפיון מלא משל עצמו. יורחב כשנגיע לתור שלו.

## מה שכבר ידוע (מהמסמך המקורי)

עוסק פטור/מורשה, חברה, שותפות, מלכ"ר. מסנן את מנוע החובות בהמשך (קבוצה ב') — לא מגדיר ברירות מחדל.

## שדות (שלד)

| עמודה | טיפוס | אילוצים | מה זה משרת |
|---|---|---|---|
| `id` | uuid | PK | מזהה |
| `code` | text | NOT NULL, UNIQUE | הפניה תוכניתית יציבה |
| `name` | text | NOT NULL | תווית עברית |
| `created_at` / `updated_at` | timestamptz | NOT NULL, DEFAULT now() | ביקורת |
