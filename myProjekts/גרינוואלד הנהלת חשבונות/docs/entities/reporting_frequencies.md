# איפיון ישות — תדירות דיווח (ישות 28 במודל המקורי)

**סטטוס: שלד מינימלי בלבד.** נוצר כתלות-FK מ-`clients.vat_reporting_frequency_id` / `clients.annual_report_frequency_id` — עדיין לא עבר איפיון מלא משל עצמו. יורחב כשנגיע לתור שלו (קבוצה ב').

## מה שכבר ידוע (מהמסמך המקורי) — אזהרה חשובה לשלב הבא

"התדירות כנתון, לא כמילה קשיחה: אורך תקופה בחודשים, חודש התחלה. מכלילה מע"מ, ניכויים, מקדמות, ומחזוריות מטלות תחת אותו מנגנון. **חובה קריטית:** תדירות אינה יוצרת תקופות בעצמה (אחרת ייווצרו תקופות כפולות לחובות שונות עם אותה תדירות) — יש להפריד לחלוטין את מבנה החלון (בתדירות) מכלל המועד (יום יעד + היסט חודשים, שיושב בתבנית החובה עצמה, לא כאן)."

## שדות (שלד)

| עמודה | טיפוס | אילוצים | מה זה משרת |
|---|---|---|---|
| `id` | uuid | PK | מזהה |
| `name` | text | NOT NULL, UNIQUE | 'חד-חודשי' / 'דו-חודשי' / 'שנתי' |
| `months_interval` | integer | NOT NULL, CHECK > 0 | 1 / 2 / 12 — נתון, לא רק תווית |
| `created_at` / `updated_at` | timestamptz | NOT NULL, DEFAULT now() | ביקורת |
