# טבלה: `services` (קטלוג שירותים — ישות 5 במודל המקורי)

**סטטוס: שלד מינימלי.** בלי סוג אספקה / אופן תמחור / תדירות חיוב / תעריף בסיס עדיין — אלה יתווספו בסבב העמקה נפרד, אחרי שנעבור על שאר קבוצה ב' (מכסה תקופתית, עסקה, הנחה, תבנית חובה) ונראה בפועל איך כל אחת מהן צורכת את השירות. אותה תבנית שהופעלה על `entity_types`/`reporting_frequencies`/`tags` בקבוצה א'.

## מה זה ולמה זה משרת

טבלת קטלוג לשירותים שהמשרד מציע (הנה"ח, שכר, ייעוץ מס וכו'). כרגע רק זיהוי בסיסי — משמש כ-FK target לישויות הבאות בשרשרת (מכסה תקופתית, עסקה).
