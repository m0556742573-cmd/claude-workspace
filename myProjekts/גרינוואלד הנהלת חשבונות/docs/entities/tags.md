# איפיון ישות — תגיות לקוח (ישות 31 במודל המקורי)

**סטטוס: שלד מינימלי בלבד.** נוצר כתלות (טבלת M2M `client_tags`) מ-`clients` — עדיין לא עבר איפיון מלא משל עצמו. יורחב כשנגיע לתור שלו (קבוצה ח').

## מה שכבר ידוע (מהמסמך המקורי)

שדה "קטגוריית סיווג" הוא הלב: חמש קטגוריות (אופי ושיתוף פעולה, ערך עסקי, מורכבות טיפול, סיכון, מאפיין תפעולי), כל קטגוריה מפעילה לוגיקה שונה (מנוע תזכורות, עדיפות, הקצאת עובד, התראה, סינון) — מאפשר לכתוב חמישה כללים גנריים במקום כלל נפרד לכל תגית. תגיות מחליפות שדות "סוג/מצב לקוח" שהיו שיפוט אנושי לא-עקבי.

## שדות (שלד)

| עמודה | טיפוס | אילוצים | מה זה משרת |
|---|---|---|---|
| `id` | uuid | PK | מזהה |
| `category` | text | NOT NULL | אחת מחמש הקטגוריות לעיל |
| `name` | text | NOT NULL | תווית התג |
| — | | UNIQUE(`category`,`name`) | מונע כפילות |
| `created_at` | timestamptz | NOT NULL, DEFAULT now() | ביקורת |
