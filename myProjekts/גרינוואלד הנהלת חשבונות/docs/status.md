# סטטוס נוכחי

**עדכון אחרון:** 2026-08-26

## מה הושלם

- תשתית שרת מוכנה: VPS נוקה, DNS/Cloudflare, Supabase self-hosted רץ ותקין, נגיש דרך `https://supabase.y-h-m.com` עם HTTPS תקין (נבדק end-to-end).
- אבטחה בסיסית: SSH מוקשח, fail2ban, Postgres/API חסומים מהאינטרנט (מאומת חיצונית).
- גיבויים אוטומטיים ל-R2 פועלים (cron יומי).
- Git repo מאותחל בתיקיית ה-workspace, קומיט ראשון בוצע.
- מערכת התיעוד הזו (docs/) בהקמה.

- **פורט 3000 (Easypanel) עדיין חשוף לאינטרנט** — מחכה לחלון זמן נוח (יצחק לא רוצה סיכון ל-n8n שרץ כל 2 דקות).
- אין אף טבלה בסכימה — מסד הנתונים ריק. **יצחק ביקש במפורש לא להתחיל בזה עדיין.**
- סיסמת ה-Dashboard לא הוחלפה (יצחק ביקש לא לגעת) — עדיין הופיעה בטקסט גלוי בהיסטוריית שיחה מוקדמת.

## הצעד הבא (כשיאושר)

בניית המיגרציה הראשונה — קבוצת הליבה (לקוח, איש קשר, עובד משרד, סוג ישות/ייחוס) — דרך Supabase CLI + קובצי migration ב-git, מוחלים על השרת דרך SSH (לא Supabase-managed cloud project, כי זה self-hosted).
